# Monitor Cinder

**NASA Space Apps Challenge 2026 · Goiânia · Challenge: Harmonization of MODIS and VIIRS Hot Spots**

Monitor Cinder turns 25 years of NASA FIRMS active-fire detections (MODIS since 2001, VIIRS since 2012) into one
consistent series for the state of Goiás, Brazil, and shows it per municipality: the historical fire pattern,
this month's anomaly, and a projection with a validated uncertainty band. It keeps running after Suomi-NPP: the
series continues on NOAA-20 and NOAA-21, calibrated to the same scale.

## What it shows

- **Map of Goiás** by IBGE municipality: anomaly vs. the historical pattern (z), cell-days or density, for any month since 2001.
- **Search by name or by coordinate**: typing `-16.68, -49.25` opens a circle there.
- **Unusual months** of a municipality (anomaly ≥ +1.5σ), one click away from the month.
- **Downloads**: monthly series (CSV), the month's fire cells with detection days, satellite and nearest locality (CSV), the calendar (PNG) and the current map (PNG).
- **Details in a side panel beside the map** (tabs Summary · Projection · History · Area · Context; a footer button opens the same view full screen): typical fire season, monthly calendar since 2001,
  MODIS × VIIRS × harmonized yearly chart, expected range for the month, fire cells inside the area, and context.
- **Circle analysis**: draw a circle anywhere; every number counts only the 1 km cells inside it.
- **Projection with a validated uncertainty band**: next 15 days, the current month and the next 6 months. A horizon is shown only
  when it beat climatology in years the model never saw; otherwise the climatological band is shown and labelled.

## Data

| Source | Role |
| --- | --- |
| NASA FIRMS — MODIS C6.1, VIIRS 375 m (S-NPP, NOAA-20, NOAA-21), science (SP) and near-real-time (NRT) | The only input of the harmonization, the anomaly and the projection |
| IBGE — municipal boundaries and names | Aggregation units |
| IBGE — Base de Localidades, 2022 Census (vilas, povoados, communities) | Map reference only: shown when zoomed in; nearest locality and straight-line distance to each fire cell |
| INPE Programa Queimadas — reference satellite (AQUA MODIS afternoon) | External validation only |
| NASA POWER (daily point API); NASA ORNL DAAC MODIS web service (MOD13Q1 NDVI, MCD12Q1 land cover) | Context tab only, never cause |

Data up to the last day FIRMS serves (NRT days are marked *provisional* in the interface).

## How the harmonization works

1. Detections with nominal or high confidence are counted as **cell-days**: a 1 km cell (EPSG:5880 grid) with at least one detection that day.
   Static thermal sources are removed.
2. **One reference scale (VIIRS S-NPP).** For each day the series uses S-NPP when it observed; otherwise NOAA-20, then NOAA-21,
   each converted by monthly factors fitted on days both satellites observed; before 2012, MODIS converted the same way.
3. Each link of the chain is checked **out of sample** (fitted on earlier years, scored on later ones).

## Evidence (all numbers come from files written by code in `api/out/`)

Generated by `npm run job:validate` on the full index (2001 → 2026-11-14).

**Internal — `api/out/internal_checks.json`**

| Check | Result |
| --- | --- |
| MODIS → S-NPP (fit 2012–2019, test 2020–2025) | WAPE 12.4 %, Pearson r 0.981 |
| NOAA-20 → S-NPP (fit 2018–2023, test 2024–2025) | WAPE 2.5 % |
| NOAA-21 → S-NPP (fit 2023–2025, test 2026) | WAPE 3.0 %, r 0.999 |
| 246 municipalities add up to the state, 311 months | max difference 2.8 cell-days (rounding bound 12.3) |

**External — `api/out/external_validation.json`** (INPE reference satellite, independent processing, Jan 2003 – Oct 2026)

| Check | Result |
| --- | --- |
| Monthly agreement, 286 months (Pearson on log) | 0.955 harmonized · 0.991 raw MODIS |
| Yearly totals, 23 years | Pearson 0.954 · Spearman 0.849 |
| Months INPE flags as unusual (\|z\| ≥ 1) | same anomaly sign in 79 of 85 (92.9 %) |
| 2026, already on NOAA-20/21 | ratio to INPE inside its 2013–2025 range in 7 of 10 months |

Units differ by design (INPE counts AQUA detections; we count harmonized cell-days), so agreement is measured by correlation, ranking and anomaly sign.

**Projection — `api/out/projection_validation.json`** (state of Goiás)

Daily negative-binomial count model (season + 1, 7 and 30-day memory) simulated forward; every horizon is a sum of the same paths.
Fitted on data up to 2014, band calibrated on 2015–2020, **scored only on 2021–2025**:

| Horizon | Skill vs climatology (CRPS) | Observations inside P10–P90 | Shown |
| --- | --- | --- | --- |
| 15 days | +18.7 % | 87.5 % | model band |
| month | +8.8 % | 90.0 % | model band |
| 6 months | −19.9 % | 87.5 % | climatology |
| next-day chance (Brier) | −5.6 % | — | hidden |

## Limits

- Per municipality the harmonization error is much larger than for the state (median WAPE 68.6 % over 217 municipalities, `api/out/internal_checks.json`) because counts are small;
  the strong claim is at state level.
- The projection describes a historical pattern with memory; it is not a cause, a risk score or a forecast of individual fires.
- NRT days can change when FIRMS publishes the science version.

## Run it

Requirements: Node 22 and a free FIRMS MAP_KEY (https://firms.modaps.eosdis.nasa.gov/api/map_key/).

```bash
cd monitor-cinder/api
cp .env.example .env        # put FIRMS_MAP_KEY=... here; never commit it
npm install
npm run dev                 # API on http://localhost:8787; first start downloads 2001 → today (≈30–50 min, cached in data/)
npm run job:validate        # rewrites the evidence in api/out/
```

Open `Mapa iterativo/index.html` through a static server on the origin allowed by `CORS_ORIGIN` (default `.env.example`: `npx serve -l 8080 "Mapa iterativo"`, then http://localhost:8080). The front never calls FIRMS; it only talks to the API.

## Stack

Front: plain JavaScript + Canvas 2D (`Mapa iterativo/`). API: Node 22, TypeScript strict, Fastify, zod (`monitor-cinder/api/`).
Optional PostGIS schema in `Tema_08_MODIS_VIIRS/db/`.
